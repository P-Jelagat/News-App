#News web app

##description
 this is a simple web app I made with HTML, CSS and JAVASCRIPT with the aid of NEWS API. I will be making improvements as I see necessary or fun as I continue to explore APIS with JAVASCRIPT.

## Features

- Fetches live news articles using the NewsAPI
- Displays dynamic news cards generated with JavaScript
- Responsive navigation bar for smaller screens
- Toggle sidebar menu using JavaScript event listeners
- Displays article images, titles, and descriptions
- Uses async/await for asynchronous API requests
- Mobile-friendly layout using Flexbox and media queries
- Interactive hover effects on cards and navigation links
- Dynamically creates and inserts HTML elements into the DOM
- Clean and modern user interface
